# Livre Blanc Citoyen

Application web de gestion des livres blancs régionaux compilés en vue de l'établissement d'un livre blanc national : cas de la Côte d'Ivoire. Projet UP-PRO ING2 STIC, École Supérieure d'Industrie, INP-HB, 2026-2027.

Équipe : SORO Koromiwonah Segneniguetenin Samuel (responsable), AZOUASSI Ômonlôla Sara Océane, GLEDE Dekongnon Henri Joël, WOGNIN Noé Phinées. Encadreur : Dr APPOH.

## Contenu du dépôt

| Dossier | Contenu |
|---|---|
| `docs/` | Exigences (PRD), spécifications techniques (TRD), données, API, parcours, UX, système de design, plan de réalisation |
| `database/` | Migrations SQL (source de vérité du schéma), tests des règles de gestion, modèles MERISE et générateurs |
| `api/` | Liste de référence des points d'API et contrat OpenAPI |
| `design/` | Système de design de départ (jetons, charte, composants), cartogramme des 33 territoires |
| `diagrams/` | Diagrammes MERISE, techniques et de parcours |
| `planning/` | Planning (fichier Microsoft Project) et générateurs des figures du rapport |
| `scripts/docs/` | Contrôle de cohérence entre documents et base |
| `.claude/skills/` | Procédures du projet pour Claude Code |

Le développement suit `docs/IMPLEMENTATION_PLAN.md` ; les consignes pour Claude Code sont dans `CLAUDE.md`. Les instructions d'installation seront complétées au lot 0.
