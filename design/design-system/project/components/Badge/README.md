# Badge
Pastille courte qui indique un statut ou une classe de priorité.

- Classes de priorité : pleine (`classe-nationale`), contour lagune (`classe-partagee`), contour ocre (`classe-specifique`). Elles restent distinguables en niveaux de gris.
- Statuts : texte explicite, jamais une couleur seule.
- Le libellé est une phrase courte en casse normale (« Partagée par 3 régions »), pas un code (`PARTAGEE`).
