# LigneContribution
Une contribution dans une liste : titre, extrait, auteur affiché, date, secteur, soutiens.

- L'auteur suit la règle d'affichage public : « Citoyen·ne de [commune] », le nom seulement si la personne l'a choisi, le nom de l'organisation pour une contribution d'organisation.
- Les lignes sont séparées par un trait, pas mises en cartes : une liste se lit de haut en bas.
- L'action « Soutenir cette contribution » est secondaire ; dans les suggestions avant dépôt, elle devient l'action proposée en premier.
