# Cartogramme
Les 33 territoires (31 régions et 2 districts autonomes) en tuiles égales, placées selon leur position approximative.

- Chaque territoire pèse autant à l'écran, quelle que soit sa superficie : c'est le principe « chaque territoire compte autant ».
- L'intensité suit l'échelle `carto-1` à `carto-6` ; le texte passe en blanc à partir de `carto-4`.
- Chaque tuile est un bouton qui ouvre la page du territoire ; un tableau équivalent est toujours proposé.
- Positions dans `cartogramme_utr.json` du projet (chefs-lieux approximatifs, à vérifier sur le référentiel officiel). La carte précise utilise les limites administratives COD-AB.
