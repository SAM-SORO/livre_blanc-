# Bouton
Déclenche une action ; son libellé dit exactement ce qui va se passer.

- **Principal** (`lbc-btn--principal`, fond `lagune-700`) : l'action attendue de l'écran. Un seul par écran.
- **Secondaire** : une alternative sûre (enregistrer, annuler).
- **Discret** : actions de ligne dans les listes et les tableaux.
- **Danger** : retrait ou suppression ; toujours suivi d'une confirmation qui rappelle la conséquence.
- **Désactivé** : seulement si une explication est visible à côté (par exemple la liste des blocages de publication).

Hauteur minimale 44 px (cible tactile). Libellés à l'infinitif ou à la première personne (« Publier ma contribution ») ; jamais « OK », « Valider » seul, ni flèche décorative.
