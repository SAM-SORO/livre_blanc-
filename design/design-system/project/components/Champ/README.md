# Champ
Zone de saisie avec son libellé, son aide et, si besoin, son message d'erreur.

- Le libellé est toujours visible, au-dessus du champ ; une aide peut donner un exemple concret.
- Les limites de longueur sont affichées par un compteur dès que la saisie commence.
- Une erreur s'affiche sous le champ, en `alerte-600`, avec un contour de 2 px, et dit comment corriger. Le focus est placé sur le premier champ en erreur.
- Taille de texte 17 px dans le champ : sur mobile, cela évite aussi le zoom automatique du navigateur.
