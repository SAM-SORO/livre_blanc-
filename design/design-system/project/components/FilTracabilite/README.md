# FilTracabilite
Le fil relie une parole citoyenne à ce qu'elle est devenue : préoccupation, livre blanc régional, priorité nationale, engagement.

- Il se lit dans les deux sens : depuis une contribution (« Où en est ma contribution ? ») ou depuis une priorité (« D'où vient cette priorité ? »).
- Le trait plein `ocre-500` s'arrête à la dernière étape atteinte ; les étapes à venir ont un nœud en pointillés et une phrase qui dit quand elles arriveront.
- Chaque étape est un lien vers sa page ; les références et dates citées sont celles des versions publiées.
- C'est le seul composant qui utilise l'ocre de façon étendue.
