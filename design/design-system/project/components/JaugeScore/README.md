# JaugeScore
Affiche un score de priorité avec sa décomposition : on ne montre jamais un score sans dire d'où il vient.

- La barre empile les points obtenus par composante (voix, urgence, étendue, portée collective) ; la partie vide est ce qui manque pour atteindre 100.
- La légende est un texte complet, lisible sans la barre ; la barre est masquée aux lecteurs d'écran.
- Les pondérations affichées sont celles de l'édition (figées dans les versions publiées).
