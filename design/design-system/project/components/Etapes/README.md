# Etapes
Indique la progression dans le formulaire de contribution en sept étapes.

- Le texte (« Étape 3 sur 7 : votre constat ») porte l'information ; la piste n'est qu'un repère visuel.
- Les étapes franchies sont en `ocre-500` (le début du fil), l'étape courante en `lagune-700`.
- La mention « Brouillon enregistré » rassure : la saisie est conservée sur l'appareil en cas de coupure.
